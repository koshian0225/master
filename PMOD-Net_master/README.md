# PMOD-Net_master

本リポジトリは、基本的には従来のPMOD-Netと同様ですが、研究のために一部変更を加えてあります。画像サイズやデータセットパスなどのパラメータは、使用する研究環境に応じて各設定ファイル内で適切に変更してください

## データセット

### KITTI-360データセット

本研究で使用するKITTI-360データセットは、本リポジトリ内の `h5_make.py` を使用して作成されます。

```bash
# KITTI-360データセットの作成例
python h5_make.py -t 500 -v 50
```

#### パラメータ説明
- `--sequence`: 使用するシーケンス番号（00, 02, 03, 04, 05, 06, 07, 09, 10から選択）
- `--train_frame`: 訓練用フレーム数
- `--val_frame`: 検証用フレーム数
